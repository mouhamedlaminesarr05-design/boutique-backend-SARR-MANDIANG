# 🛒 Boutique

Application web d'e-commerce développée avec **Laravel** permettant aux utilisateurs de parcourir des produits, les ajouter au panier et passer des commandes.

## Fonctionnalités

- Gestion des produits
- Gestion des catégories
- Panier d'achat
- Authentification des utilisateurs
- Gestion des commandes
- Tableau de bord administrateur

## Technologies

- Laravel
- PHP
- MySQL
- Blade
- Bootstrap

## Installation

```bash
composer install
php artisan migrate
php artisan serve
```
